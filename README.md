# Caldwell SJS - Next.js with Clerk Authentication

A Next.js 15 application using the App Router with Clerk authentication integration following the latest best practices.

## 🛠️ Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint
